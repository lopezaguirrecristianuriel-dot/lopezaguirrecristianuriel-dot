## ⭐ Proyecto principal

### 🤖 SITHET-XBC — Asistente Personal de Inteligencia Artificial

Mi proyecto principal actualmente es **SITHET-XBC**, un asistente personal de IA para PC desarrollado en Python.

XBC busca integrar diferentes tecnologías para permitir una interacción más natural con el equipo mediante:

* 🎙️ Interacción por voz
* 🤖 Integración con modelos de Inteligencia Artificial
* 🧠 Memoria y contexto
* 👁️ Procesamiento de información visual
* ⚙️ Automatización y ejecución de tareas
* 🖥️ Interacción con el sistema operativo
* 🛠️ Herramientas para consultar información del sistema
* 🎨 Interfaz gráfica con PySide6
* 🔮 Interfaz visual tipo holográfica

El proyecto se encuentra en **desarrollo continuo**, por lo que nuevas funciones y mejoras se irán incorporando progresivamente.
